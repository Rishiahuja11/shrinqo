🚀 Quick start

1
Shorten your first link — no account needed:
curl -X POST https://short.smp45.qzz.io/api/v1/shorten \
  -H "Content-Type: application/json" \
  -d '{"url":"https://github.com"}'
2
Create an API key (30 s): register → open keys → copy the lsk_… secret once.
curl -H "Authorization: Bearer lsk_YOUR_SECRET" \
  https://short.smp45.qzz.io/api/v1/auth/me
3
Claim a custom alias & expiry:
curl -X POST https://short.smp45.qzz.io/api/v1/shorten \
  -H "Authorization: Bearer lsk_YOUR_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/sale","alias":"black-friday","expires_in":604800}'

→ live for 7 days at /black-friday, then it returns 410 Gone automatically.

📐 Conventions

RuleDetail
Success{"ok":true,"data":…} — creation returns HTTP 201, everything else 200
Error{"ok":false,"error":{"code":"…","message":"…"}} with a meaningful status (400/401/403/404/409/410/429/502)
Rate limitsEvery response carries X-RateLimit-Limit / -Remaining / -Reset; exceeding returns 429
PaginationList endpoints accept ?limit= (1–200) and ?offset=, and answer with total
DeduplicationIdentical content returns the existing link (deduplicated:true) instead of a new row
CORSAll /api/* endpoints allow cross-origin calls

Health & index

GET/api/v1/healthpublic

Liveness + version + uptime. No auth.

GET/api/v1public

Machine-readable endpoint catalog. Full spec: GET /openapi.json (OpenAPI 3.1).

Account & keys

POST/api/v1/auth/register

Body {name, password} — name: 3–20 chars letters/digits/_; password ≥ 6. Sets session cookie.

POST/api/v1/auth/loginauth

POST/api/v1/auth/logout · /api/v1/auth/logout-all

POST/api/v1/auth/passwordsession only

Body {current_password, new_password}. Revokes other sessions.

GET/api/v1/auth/meauth

Username, created date, link count, lifetime clicks.

GET/api/v1/keys · POST/api/v1/keys · DELETE/api/v1/keys/:idauth

The create response contains secret exactly once — store it immediately.

Create links

POST/api/v1/shortenanon ok

FieldTypeNotes
url or textstringURL (http/s) or paste up to 100 k chars — one required
aliasstringauth required. 1–32 chars a-z A-Z 0-9 _ -, no reserved words
expires_insecondsoptional, max 31 536 000 (1 year) → link serves 410 after
namestringoptional label

POST/api/v1/shorten/bulkanon ok

Body {links:[{url}|{text}, …]} — up to 25 items; per-item success/error results.

POST/api/v1/filesanon ok

Raw bytes as body, X-File-Name header, ≤ 100 MB. Chunked to GitHub storage; served back at /:id/dl.

Manage links

GET/api/v1/linksauth

Your links. Query: ?kind=url|text|file, ?q=search (matches url/text/name/id), ?limit=, ?offset=.

GET/api/v1/links/publicpublic

Recent public feed with pagination.

GET/api/v1/links/:idpublic+

Public view hides private fields; owners additionally get enabled, expires_at and full paste text.

PATCH/api/v1/links/:idowner

Any of: {url}, {text}, {name}, {enabled:true|false}, {expires_in:seconds|null}. Response lists changed fields.

DELETE/api/v1/links/:idowner

Removes the link and its dedup entries — the same content can be shortened again afterwards.

Platform totals: links, lifetime clicks, last-24 h clicks, per-kind counts.

OpenGraph scrape of any URL (title/description/image) — the engine that powers link previews. 10/min.
