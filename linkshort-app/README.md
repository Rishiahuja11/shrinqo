# Shrinqo

Shrinqo — cinematic URL shortener, paste host, and file sharing platform.

## Features

- URL shortening with custom slugs
- Paste hosting with syntax highlighting
- File uploads up to 100MB
- 3-step ad monetization interstitial
- Responsive dark UI with cinematic animations
- API with token-based auth
- SQLite database with WAL mode
